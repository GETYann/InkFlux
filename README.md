Avez InkFlux, vous pourrez gérer votre stock de cartouche facilement en drag and drop. 
Vous pourrez créer, vos employés, vos services, vos imprimantes, vos consommables, et gérer simplement les stocks. 
Vous aurez des alertes de niveau, les flux et le suivi.
